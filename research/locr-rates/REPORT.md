# LOCR 罕贵度与封入配置调查

核查日期：2026-10-07。对象为项目使用的日本国内版 OCG「LIMIT OVER COLLECTION - THE RIVALS -」，不是 THE HEROES，也不把亚洲日文版或购买赠送的 LOSP 特典包混入统计。本次只整理资料，未修改游戏数量、卡池或概率。

后续 GMR 专项见 [GMR.md](GMR.md)：每卡种 001/100–100/100、独立亚洲版 /100A、18 种完整卡池与工艺；新二手资料支持 GMR 替换超框位，准确爆率仍未确认。下文旧结论对应首次调查，涉及替换位置的部分以专项记录为准。

## 官方已确认

KONAMI 产品页：<https://www.yugioh-card.com/japan/products/locr/>。

- 发售日为 2026-03-20；每包 4 张、每盒 15 包，即每盒 60 张。
- 全 80 种卡：基础 UR 38 种、SR 42 种。没有 N 普通卡或 R 字闪卡。
- 每包定价 385 日元含税，整盒按 15 包计算为 5,775 日元。

| 罕贵度 | 收录范围 | 说明 |
| --- | --- | --- |
| SR / Super Rare | 42 种 | 基础面闪 |
| UR / Ultra Rare | 38 种 | 基础金字／金闪；其中 18 种另有 Overframe 版 |
| SER / SE / Secret Rare | 全 80 种 | 官方说明所有卡均有此规格 |
| PSER / PSE / Prismatic Secret Rare | 全 80 种 | 官方明确其中 18 种为 Overframe 卡；不要再额外加 18 种算成 98 种 |
| UL / UTR / Ultimate Rare | SR 卡中的 21 种 | 浮雕；与 UR / Ultra Rare 是不同罕贵度 |
| CR / Collector's Rare | SR 卡中的 21 种 | 收藏家罕贵；与 UL 是不同表面工艺 |
| GMR / Grandmaster Rare | UR 卡中的 18 种 | 特殊序列号限量规格；官网标注「100枚限定シリアルNo.入り」 |

Overframe（超框／出框）属于版式，UR 与 PSER 都存在超框规格，不能当成独立于 UR／PSER 的一种闪卡工艺。GMR 的限量数量需结合发行版本和卡种理解，不能解释成普通开盒概率；本次不把亚洲版编号或数量并入日版。

## 实际开盒的常见配置

以下是多个玩家记录和攻略资料一致出现的配置，不是 KONAMI 公布的概率或保底承诺。

每包通常是 **2 张 SR + 1 张普通 UR + 1 张特殊卡位**；特殊位可为 SER、UL、CR、PSER 或 Overframe 卡。因此不应把四张卡各自按同一组概率独立抽取。

| 每盒卡位 | 常见数量 | 是否计入 60 张 |
| --- | ---: | --- |
| SR | 30 | 是 |
| 普通 UR | 15 | 是；不包含下面的超框位 |
| SER | 9 | 是 |
| UL / UTR 浮雕 | 2 | 是 |
| CR 收藏家 | 2 | 是 |
| 通常 PSER 卡位 | 1 | 是 |
| Overframe 卡位 | 1 | 是；通常 UR，部分盒升级为 PSER |
| 合计 | 60 | GMR 特殊情况的替换规则未确认 |

抽到超框 PSER 时，它通常替换该盒的超框 UR，而不是凭空多送一张卡；实际记录存在「通常 PSER 1 张 + 超框 PSER 1 张」的同盒结果。普通情况下 UR 总数为 16 张（15 普通 + 1 超框）；超框位升级后为 15 张 UR、2 张 PSER。GMR 出现时替换哪个卡位、是否影响其他配额，本次没有可靠记录可确认。

整箱常见为 **24 盒**，由开盒资料交叉支持，KONAMI 产品页本身未写外箱盒数。对应 360 包／1,440 张卡；不要使用项目当前的 12 盒／箱作为实物证据。

## 超框 PSER 与 GMR 的爆率

### 超框 PSER

CUBE 和 alhide 的 THE RIVALS 开盒文章都写到整箱约 6 张超框 PSER。结合 24 盒／箱，折算为 **约 25%／盒，平均约 4 盒一张**。这属于玩家说法，没有找到完整整箱逐包原始统计来证明它是所有批次固定配额；不能承诺每四盒必出，也不能把 25% 当作每张卡的概率。

额外核对了五篇有文字结果的开盒记录：

| 来源 | 盒数 | 超框 PSER | GMR |
| --- | ---: | ---: | ---: |
| 遊戯王マスターラボ | 3 | 0 | 0 |
| 遊戯王の軌跡 | 3 | 0 | 0 |
| CUBEの部屋 | 3 | 2 | 0 |
| alhide / Ameblo | 1 | 0 | 0 |
| あいすの隠れ家 | 6 | 2 | 0 |
| 本次可核对的小样本 | 16 | 4 | 0 |

4/16 恰好为 25%，只能表示这些公开记录的结果。样本少、有发表选择偏差，也没有证明它们来自独立随机批次，不能把这个比例升级成已测定的总体概率。本次未下载或完整观看大样本开箱视频，视频标题里的盒数不计入样本。

### GMR

官方确认 GMR 的存在、18 种适用卡和序列号限量规格，没有找到官方公布的单包／单盒／单箱出率。限量数量不足以推导概率，还缺少总发行量和投放规则。上述 16 盒没有 GMR 也不足以估计其低概率，不能据此写成 0%。后续交叉确认每卡种有 001/100–100/100 的 100 个编号；日版 LOCR 为 1,800 个正式编号名额，亚洲日文版 /100A 另计。二手资料支持 GMR 替换超框位，证据与限制见 `GMR.md`。

网上流传的百分比或「若干箱一张」不能作为当前确定配置。其中一篇 GMR 商业文章同时出现概率单位不明、百分比与所需盒数不符、60 箱写成 6,000 盒等问题，而且主要讨论 HEROES；未采用它的具体概率。

## 与项目现有规则的差异

`src/model.js` 目前为 12 盒／箱、10 包／盒、10 张／包，N/SR/UR/SER/PSER 的独立权重为 58/26/12/3.5/0.5。这些是现有模拟规则，不能对应本次查到的 LOCR 实物。

如后续要求实物配置模拟，资料支持以「盒内配额 + 包内卡位」发牌，添加 UL、CR、GMR，并分开记录 `rarity` 与 `frame`。超框 PSER 的 25% 可作为明确标注的暂用估计；GMR 概率应保留未确认状态，不能编造官方数值。卡名和图像继续从真实卡池加载，不把占位青眼白龙当成整盒卡池。
