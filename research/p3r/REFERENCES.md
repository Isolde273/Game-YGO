# P3 Reload 界面重构 · 2026-10-07

用户确认按《女神异闻录 3 Reload》方向继续。研究时未打开旧界面的截图；旧模板只用于识别事件、数据与可访问性接口。设计重新建立，保留手机购买、实体收藏册与开盒空间的产品思想。

## 视频逐帧记录

来源：[BV1pKbP6dEdj · 决战鹰角美术之巅](https://www.bilibili.com/video/BV1pKbP6dEdj/)。通过公开视频信息和播放接口获得 360p 研究副本，大小 2,061,130 字节。实际 857 帧，约 30 fps、28.57 秒。全部帧解码后分为 8 张标注帧号／时间的缩略图，每张至多 120 帧，1280×1020；另有每秒总览与帧差统计。逐批查看全部图板，重点检查图形变化区间，不读取视频二进制或图片编码到会话。

## 网站与方向

指定来源：[ignoredone 美术资源系统](https://www.ignoredone.space/index.php/arknights_design/)。2026-10-07 实际页面为《明日方舟》资源索引，公开 API 返回 95 组资源，没有标注 P3R 的分组。向用户说明后，用户确认按 P3 Reload 继续，因此不将该网站内容伪称为 P3R 原始设计。

网站研究包括年份／项目索引、缩略资源组织、12 个 2025 年项目的缩小封面总览，以及 2025/0403「离解复合」的两张 UI 参考图。图片均先用 OSS 参数缩放至 1100px 或更小。重点学习：单个主题大视觉、分区稳定的功能信息、强对比选中态、信息和装饰各有层级。视频的 4–7 秒蓝青圆环段作为动效构图依据。

补充权威来源：[ATLUS · ペルソナ３ リロード](https://p3re.jp/)。P3 Reload 的深蓝／亮蓝／青白、倾斜粗字、圆形元素、非对称视觉与短促进入作为视觉方向；青眼白龙图形、图标与实际排版为本项目原创。

## 最终页面与资源

- 主页：纵向倾斜功能菜单、原创几何白龙、圆环构图、实时持有与收藏数据。
- 收藏册：浅色实体双页、卡袋与书环，右侧版本索引；窄屏每页纵向三卡，索引移至下方。
- 仓库：分类与数量索引、搜索排序、模块化包装和单卡货架；窄屏改成横向筛选。
- 购买：独立实体手机、三应用渠道、余额与补给；桌面背景为蓝色斜块与青色圆环。
- 设置：分类跳转与并列操作面板；窄屏纵向排列。
- 空间：冷色照明；蓝青 HUD、拆封菜单、多选栏、单卡整理、收藏／仓库接收区。
- 图标：`src/icons.js`，统一 24 单位实心剪影与镂空；原始几何插画 `public/assets/reload-dragon.svg`，桌面／网页图标更新为相同语言。
- 文案：只保留功能名称、商品名称、数量、状态、规则和操作说明。

所有运行时资源均在本地。参考网页、视频及缩略图仅留在研究目录，不加入游戏运行时。原界面资源未删除；当前入口不加载原来的纸张、印章、人物或页面样式。
