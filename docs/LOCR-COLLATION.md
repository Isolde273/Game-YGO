# LOCR 配额与真实开包接入

2026-10-09。接续 [统一卡牌数据与存档第一阶段](CARD-DATA-SAVE.md)。已接入真实发牌、封入配额、vol.2 赠包与实体编号；最新版本4采用独立概率，取代此前三箱固定一张GMR的批次方案。328规格的游戏完整工艺接入见 [CARD-FINISHES.md](CARD-FINISHES.md)。

## 已确认规则

24盒/箱、15包/盒、4张/普通包。每包固定2 SR、1普通UR、1特殊位；每盒30 SR、15普通UR、9 SER、2 UL、2 CR、1普通PSER、1出框位。SR和普通UR分别在盒内无重复；不同罕贵度可出现同一卡种。

| 每箱出框位 | 无GMR箱 | 有GMR箱 |
| --- | ---: | ---: |
| UR-OF | 18 | 18 |
| PSER-OF | 6 | 5 |
| GMR | 0 | 1 |

每箱独立以1/3概率出现一张GMR，命中时随机替换六张PSER-OF中的一张；每箱最多一张GMR。连续购买三箱可能出现0–3张，不跨订单设保底、补偿或累计计数。初始整箱、前次购买及其他商品不会影响下一箱的概率。

单独购买的卡盒仍保留上述盒内配额；仅出框位按UR-OF / PSER-OF / GMR的54:17:1权重独立分配，即75%、23.6111%、1.3889%。因此散盒GMR概率为1/72。

单独购买的卡包固定2 SR、1普通UR、1特殊位；两张SR不重复。特殊位按整箱边际概率独立抽取，不从虚拟盒或三箱批次取货：

| 特殊位 | 权重（总计1080） | 概率 |
| --- | ---: | ---: |
| SER | 648 | 60% |
| UL | 144 | 13.3333% |
| CR | 144 | 13.3333% |
| PSER | 72 | 6.6667% |
| UR-OF | 54 | 5% |
| PSER-OF | 17 | 1.5741% |
| GMR | 1 | 0.0926%（1/1080） |

整箱内拆出的盒、盒内拆出的包继续展开购买时确定的内容，遵守上层封装配额；它们不重新按散购概率抽取。

单笔盒订单每三盒赠1包vol.2，余盒不跨订单累计；单笔整箱订单每箱赠8包。拆开箱子不再发赠包；散包和单卡无赠包。价格沿用原游戏币价格。赠包和正品一起接受库存容量检查；任何订单失败均不扣币、不消耗货源。

vol.2每包1张，必为PSER-OF。10种等概率、有放回独立抽取，普通LOCR池不混入特别包卡种。普通包与特别包分别支持单包/五包开启。

## 数据和存档

- `src/game/collation.js`：确定性盒配额、整箱独立1/3概率、散盒/散包权重、GMR预留与校验。
- `src/game/model.js`：购买时确定未拆封内容、按现有封装展开、真实规格入库与赠包。
- `public/vol2-catalog/`：官方核实的LOSP-JP011至JP020十种卡；与LOCR的80种/318规格分开保存。统一查询为90种/328规格。
- `scripts/prepare-vol2-catalog.py`：从官方各卡收录页核对编号，使用既有本地日文出框图片生成特别包卡面。官方来源、图源文件和SHA256记录在manifest；HTML核对证据留在test-results。特别包包装为游戏内示意设计。
- `scripts/generate-card-data.mjs`：同时生成两个离线卡池；额外生成没有001预览号的GMR底图供游戏使用，工艺图鉴保留原预览底图。

版本4保留原存储键`ygo-duel-archive-v1`。箱/盒记录种子与出框位，包记录具体规格；依赖固定版本的发牌算法展开。无需将整箱1440张卡都展开写入存档。所有随机结果在获得商品时确定；更改开启顺序、单包/五包、重载或换页面均不会重抽。

版本1/2未开封商品在迁移时一次性分配新配额，保留原ID、位置与既有真实卡牌。版本3升级先校验已有封装和旧批次，再保留全部已购买商品的既定结果，只清除尚未购买的供货队列及其编号预留。已经拆开的旧箱内现存卡盒保持原数量，不补发卡盒或赠包；真实卡牌实体照旧保留。2026-10-09 起旧占位卡退出游戏，保存清理结果前另存原始占位库存备份，详见 CARD-DATA-SAVE.md。

首次覆盖旧版本分别保存原文到`ygo-duel-archive-v1-backup`、`ygo-duel-archive-v2-backup`或`ygo-duel-archive-v3-backup`，备份互不覆盖；备份失败时原存档不被覆盖。

商品抽中GMR时，从18种卡各001–100中预留未用编号；预留商品与已持有账册共同防重。拆包后同一编号移入所有权账册；三维卡面、整理与册页显示实体编号，详情列出持有编号。编号全部耗尽且抽中GMR时整笔订单失败、不扣款；未抽中GMR的商品仍可生成，不伪造重复编号。

三维包装现为6×4盒/箱、15包/盒，容器碰撞尺寸、槽位、动画释放数量和无障碍交互同步更新。vol.2有独立包装、库存名称及拆包家族，不和普通包混剪。
